# /scaffold-app

Follow the **scaffold-archipy-app** skill.

1. Ask for package name, ArchiPy extras, and optional first domain.
2. Generate config, helpers tree (`utils` / `decorators` / `interceptors`), models stub, and `.env.example`.
3. Point the user to `/docs-quickstart` and `/scaffold-adapter` for next steps.

Docs: https://syntaxarc.github.io/ArchiPy/getting-started/quickstart/
